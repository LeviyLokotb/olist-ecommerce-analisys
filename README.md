# Olist E-Commerce: анализ доставки и оценок клиентов

Анализ бразильского датасета Olist (~100 тыс. заказов): как время доставки
связано с оценками клиентов, какие штаты требуют внимания логистики,
и является ли штат AM аномалией или случайностью.

## Вопросы исследования

1. Как распределена выручка компании по штатам Бразилии 
2. Связано ли время доставки с оценкой заказа 
3. Какие штаты проблемные с точки зрения логистики
4. Штат AM показывает высокие оценки при самой долгой доставке.
Это реальная аномалия или статистический шум?

## Данные

Датасет Olist Brazilian E-Commerce (9 таблиц, ~100 тыс. заказов, 2016–2018).  
В проекте используются:
- `customers` -- клиенты и их штаты 
- `orders` -- заказы, даты покупки и доставки 
- `order_pauments` -- платежи 
- `order_reviews` -- оценки клиентов 

Источник: [Kaggle -- Olist Brazilian E-Commerce](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

Docker образ данных, загруженных в postgresql: [horlar/olist-cleaned-data](https://hub.docker.com/r/horlar/olist-cleaned-data)

## Технический стек

- __PostgreSQL__ -- хранение данных, SQL агрегация 
- __Python__ (Pandas, SQLAlchemy) -- загрузка и анализ 
- __SciPy__ -- статистические тесты 
- __Matplotlib__ -- визуализация 
- __Jipyter Notebook__ -- отчёт 

## Что сделано

### SQL

- Агрегация выручки, среднего чека, времени доставки и оценок по штатам 
- Обработка неуникальности в `order_payments` -- несколько строк с одинаковым id на заказ.
Предотвращено предварительной агрегацией через CTE, чтобы избежать ошибок с join.
- Фильтр по доставленным заказам и отсеивание штатов с маленькой выборкой (<100 заказов)

### Анализ

- Корреляции между метриками на уровне штатов 
- Поиск выбросов по времени доставки (критерий mean+1.5$\sigma$)
- Проверка гипотезы о AM: доверительный интервал, t-тест Уэлча, оценка размера эффекта

## Выводы

- __Выручка сконцентрирована__: SP, RJ, MG -- топ-3 штата по выручке 
- __Время доставки и оценки связаны__: корреляция -0.58 на уровне штатов 
- __Проблемные штаты по логистике__: AL (24.5 дня, оценка 3.84)
и AM (26.4 дня). PA формально не выброс, но на графике
виден как проблемный. 
- __AM штат -- не аномалия__: Разница средних с остальными штатами 0.065 балла,
p-value = 0.53, размер эффекта ~0.05$\sigma$. Статистических оснований считать
AM отличающимся нет.

## Примечания
- В order_reviews не каждый заказ имеет отзыв. Используется `left join`, `AVG` игнорирует `NULL` 
- Выводы сделаны на уровне штатов а не отдельных заказов
